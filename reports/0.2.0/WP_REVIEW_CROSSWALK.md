# WordPress review crosswalk for Small Tools 0.2.0

Date: 15 October 2026. This public engineering crosswalk applies the maintainer's shared review lessons to all fifteen products. Private review emails, account details and their local evidence are not distributed. Historical approval of SEO Suite is not approval of Small Tools. Exact installed-package hashes and observed checks are in `PACKAGE_REPORT.md` and the product release reports.

## Additional defects reproduced before publication

- MediaMap/UseMap: wpdb can return an empty array after a failed query. The scanner now inspects last_error immediately and returns REST 503, rather than false success. Large stored bodies are excluded in SQL before full post-cache priming and produce explicit incomplete reports. MediaMap checks exact IMG class tokens instead of searching arbitrary text.
- StockDigest: a durable claim must be confirmed before attempting mail. Settings/state must be read authoritatively after acquiring the lock, so stale request caches cannot bypass recipient erasure. Product existence is checked again after a lock wait.
- DownloadRescue: WC_Order::save can catch a storage exception internally and return an existing ID. Fresh CRUD readback confirms the granting/approved state before entitlement/mail effects; fault-injection tests cover swallowed failures and replay.
- InvoiceRoute: multiline dbDelta schema declarations are used and repeat activation is tested; a single-line declaration misled the schema parser during local reactivation.

The individual reports record the actual regression/fault-test results. These are local findings and fixes, not new WordPress.org decisions.

## Remaining release work

The code and source packages are candidates for use and review. Final product pages, directory assets/readme validation, naming clearance, physical mail-client/mobile/Safari/Firefox/assistive-technology checks, broader third-party integrations and large data volumes remain scoped release gates. Compatibility with the separate BriefGo and SEO Suite packages is not established by this fifteen-tool test site. No payment credentials, production customer data or private review mail is required to reproduce the local source tests.
