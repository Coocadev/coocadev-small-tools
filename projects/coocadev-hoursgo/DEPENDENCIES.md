# Dependencies and licensing

Coocadev HoursGo 0.2.0 runtime is original readable PHP, GPL-2.0-or-later (full `plugin/LICENSE`). WordPress6.9+ and PHP8.1+ are separately installed hosts. No bundled runtime libraries, fonts, images, remote APIs, JS, generated assets or shared plugins. No build required. WP-CLI, Plugin Check and WPCS are development-only and excluded from install ZIPs.
