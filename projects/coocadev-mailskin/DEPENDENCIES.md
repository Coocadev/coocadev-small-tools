# Dependencies and licensing

Coocadev MailSkin 0.2.0 runtime is original readable PHP, GPL-2.0-or-later (full `plugin/LICENSE`). WordPress6.9+ and PHP8.1+ are separately installed hosts. No bundled third-party runtime libraries/fonts/images, remote APIs, minification or shared plugin. A configured logo is user-selected site media, not a bundled asset or tracker. Existing site SMTP/transport is neither replaced nor distributed. WP-CLI, Plugin Check and WPCS are development-only and excluded from install ZIPs.
