# Security policy

These plugins are initial release candidates. Review the supported flows and observed environment in the product report before deploying. Updates receive a new version and a new exact-package verification; an old PASS is not proof of a later version's safety.

Please report a suspected vulnerability privately to **hello@coocadev.com**. Include the affected plugin/version, required user role, an isolated reproduction and the expected/observed behavior. Do not include production secrets, customer records or unredacted authentication cookies. An acknowledgment or fix deadline is not guaranteed by this document.

Until a fix or coordinated disclosure, avoid posting live credentials, a working exploit against someone else's site or private customer data in public issues. General non-security bugs can be reported in the public repository.

Deactivation is not a data-deletion mechanism. Follow each plugin's documented uninstall/retention policy. Publicly distributed PDF versions or already sent emails cannot be recalled by uninstalling a plugin.
